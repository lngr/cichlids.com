Überblick

cichlids.com ist eine seit den 2000er-Jahren bestehende, große englischsprachige Foto-Sharing- und Bewertungs-Community für Buntbarsch-Halter. Nutzer laden Fotos ihrer Fische und Aquarien hoch, ordnen sie einer Spezies-Taxonomie zu, bewerten und kommentieren sie und pflegen Tank-Profile. Technische Basis ist eine TYPO3-4.x-Anwendung (Extension user_cichlids), überlagert von einem modernen Angular-Frontend mit PHP-REST-API, einem dynamischen Bildserver, AWS-Lambda-Diensten und Auth0-Login.

Stand der Datenbasis

Die Datenbasis ist vollständig und konsistent verfügbar. Alle drei Produktiv-Datenbanken sind charset-korrekt (kein Mojibake) in einem MySQL-5.7-Stack wiederhergestellt, der Bildbestand (≈235 GB) liegt entpackt vor, und der komplette Anwendungs-Quellcode ist vorhanden (Frontend, PHP-API, TYPO3-Site samt Custom-Extension, Forum, Serverless-Teile).
  • Datenbanken: cichlids_typo3 (Kerndaten), cichlids_phorum5 (Forum), cichlids (leerer Event-Store des unfertigen .NET-Prototyps) — laufend in MySQL 5.7 + phpMyAdmin.
  • Bilder: Original-Dateien praktisch vollständig erhalten; die Resize-Pipeline überschreibt Originale prinzipbedingt nie (separater Cache).
  • Quellcode: Angular-7-Frontend, PHP-Slim-API, TYPO3-Extension user_cichlids, Resize-Bibliothek libcichlids, AWS-Lambda-Dienste, Phorum-Forum.
  • Auth0-Export (12.147 Konten) liegt vor.
Ziel: Eine moderne Mobile-First-App („Instagram für Buntbarsch-Enthusiasten") auf Basis dieser Bestandsdaten. Beim Deployment ist nur eine einmalige Datenmigration aus dem aktuellen Stand nötig.

Architektur

Öffentlicher TLS-Endpunkt ist nginx (Edge/Router) auf CentOS 6.10, das pfadbasiert auf fünf lokal gebundene Backend-Container routet. Daten liegen in MySQL und im Dateisystem; Original-Bilder werden über einen dynamischen Bildserver in beliebigen Größen ausgeliefert.

PHP-API – Endpunkte (Slim 3)

  • pictures: list / view / edit / delete / discard / type + Kommentare
  • upload: /upload/files (Fine Uploader) → convertToPicture | TankPicture | ProfileImage | AvatarImage
  • tanks: list / view / edit / delete, addFromPicture, Bildverwaltung, Kommentare
  • comments: list / delete · users: /userid/{id}, /authuser

Auth via Auth0-JWT (RS256, In-Process-Verifikation; Rollen-Claim http://www.cichlids.com/roles). Daten in cichlids_typo3 (user_cichlids_*, fe_users, fe_users_auth0, tx_realurl_uniqalias für Slugs). Uploads: api_uploads → user_pics. Neue Kommentare/Logins werden auf AWS SNS publiziert (sync_*.php).

TYPO3-Extension user_cichlids – Plugins
  • pi1: Anzeige/Listing + Legacy-Moderation (xajax Report/Rate, Delete/Suspend)
  • pi2: Upload/Bearbeitung von Bildern & Tanks, Galerie-Verwaltung
  • pi3: neuere OO-Rendering-Schicht (Tanks, Pictures, Profile, Species, Comments)
  • Definiert das komplette user_cichlids_*-Schema (ext_tables.sql, tca.php); banlist.php = Spam-Filter.
